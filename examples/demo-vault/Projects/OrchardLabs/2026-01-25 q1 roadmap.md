# Q1 Roadmap — Orchard Labs

Q1 goals for the fruit-inventory service: (1) ship the normalized schema, (2) integrate the cold-storage vendor API feed, (3) reduce duplicate-SKU incidents to zero. [[Avery Quinn]] owns goal 2; [[Sam Rivera]] owns goals 1 and 3.

## Goal 1: normalized schema

Based on the [[2026-01-10 schema decision|Fruit DB Schema Decision]]. Done when every SKU row points to a harvest batch in production and the old flat table is read-only.

## Goal 2: cold-storage vendor feed

Pull the Glacierline feed described in the [[2026-01-20 vendor email|Cold-Storage Vendor Email]] into the service every 15 minutes. Done when a pallet's temperature history is visible next to its SKU.

## Goal 3: zero duplicate-SKU incidents

After the [[2026-01-22 dup sku bug|duplicate SKU bug]], the bar is zero incidents for the rest of the quarter. Measured from the import log's rejected-row count.

## Not this quarter

- Forecasting ripeness from temperature data. Parked until the feed is stable; it became [[Ripeness Forecast]] in March.
- A customer-facing stock page.

Checklist for launch: [[Q1 Launch Checklist]].
