# Decision Record: audit trail approved

Decision: adopt the append-only audit trail from [[Sam Rivera]]'s spec ([[2026-02-15 spec|Spec: SKU history audit trail]]). [[Avery Quinn]] signs off; rollout targeted for Q2. Orchard Labs' inventory API team will own the migration.

## Context

The normalized schema shipped in [[2026-02-05 release notes|v1.4]], so every SKU now has a harvest batch to hang its history on. The fruit-inventory service has shipped everything on the Q1 list; this is the first decision about what comes next.

## What was decided

- Audit rows are append-only and kept for seven years, matching how long we keep invoices. This answers the open question in the spec.
- Temperature readings stay out of the audit table.
- All SKU writes move behind a single function before the audit table goes live.

## Consequences

- Q2 starts with a refactor nobody outside the team will notice.
- Reporting can answer "what did we think we had on this date", which customers like Bramblecrest Grocers have asked for.

Logged in the [[Decision Log]].
