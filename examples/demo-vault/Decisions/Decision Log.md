## How we write decisions

1. One page per decision, named with the date first.
2. Say what was decided in the first sentence. Context comes after.
3. Name one owner, even when several people agreed.
4. If a decision is reversed, add a new entry instead of editing the old one.

Template fields: date, decision, context, options considered, consequences, owner.
